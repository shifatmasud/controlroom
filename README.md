# Control Room

A minimalist daily dashboard.

- **CMS:** Notion database "Control Room · Updates"
- **Host:** Framer project "Control Room"
- **Version control:** this repo

## Data model

See `notion/schema.md`. Each row is one update: a mail, a code event, a calendar item, a work item or a note.

## Design

See `design/tokens.json`. Apple-style: SF system font, generous white space, soft cards, one accent colour.
